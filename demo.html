Can one follow-up question help a weak monitor?

In a swarm, agents post progress claims and other agents build on them. A weak, trusted monitor has to decide which claims are false, and the more agents there are, the more logs it has to search. Here it gets one move a passive monitor doesn't have: ask the agent a question, then check the answer against the logs.

Live demo (ish): a scripted replay with made-up example claims. It shows how the method works; the real numbers are in the chart below.

What the real experiment found

83 log-verifiable progress claims from 14 frontier agents in the AI Village, labels checked against each agent's own command outputs. AUROC for flagging false claims:

Weak = Qwen 3.5 9B, strong = GPT-5-mini. The follow-up recovers 76–82% of the weak-to-strong gap. Two caveats: a peer's "verified" label raised the spread of a false claim from 19% to 41%, and agents that falsify their own tool outputs fool both monitors. Project page · code
